## 下一步建议（按优先级）

1. **先把「已设计」的 23 项写进新的 TUNING/engine**（替换旧的「回合制 + 比数字」那套）→ 这 23 项是骨架，骨架不对后面全白做。
2. **建筑体系里挑 3-4 个最小可行项先落地**：粟田 / 麻田 / 箭塔 / 城墙——四样东西+90天时间线就能跑通一局。
3. 「待设计」里优先级最高的是 **土的三档数值 + 箭塔的削弱量**——这俩直接决定「好不好玩」。
4. 衍生链（桑→丝→布→衣）和民生建筑（酒馆/茶坊）属于「锦上添花」，可排在后面。
